Interactive Investment Portfolio Allocation Dashboard

Built an interactive, browser-based portfolio allocation dashboard using HTML, CSS, and JavaScript.

The application transforms CSV-based investment allocation data into a four-slide presentation, visualizing account balances, ETF allocations, and weighted historical returns across taxable and retirement accounts.

Features include interactive donut charts, dynamically generated tables, consolidated portfolio calculations, and keyboard-based slide navigation.

The dashboard is completely self-contained, requiring no external libraries, frameworks, or server-side dependencies.
